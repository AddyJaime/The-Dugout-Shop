# The Dugout Shop

> **Educational Project — No Real Merchandise is Sold**

A full-stack e-commerce platform simulating an MLB merchandise store, built for learning purposes.

## Stack

- **Frontend:** Next.js, TypeScript, Tailwind CSS
- **Backend:** Node.js, Apollo Server, GraphQL Federation
- **Database:** PostgreSQL (per service)
- **Auth:** Keycloak, OAuth2, OpenID Connect
- **Infra:** Docker, Kubernetes, Terraform
- **Monorepo:** Turborepo + pnpm

## Status

🚧 Under active development.
